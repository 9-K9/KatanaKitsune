# Technical Requirements

# Game Engine

Godot 4.3

## Language

GD Script

# Hardware Requirements

## Minimum Specs

- OS: Windows 7 SP1+ / macOS 10.12+ / Ubuntu 18.04+
- CPU: Dual-core processor, 2.0 GHz or better
- RAM: 4 GB
- GPU: Graphics card with OpenGL 3.3 / OpenGL ES 3.0 support
- Storage: 2 GB available space
- Display: 1280x720 resolution

## Recommended Specs

- OS: Windows 10 / macOS 10.15+ / Ubuntu 20.04+
- CPU: Quad-core processor, 3.0 GHz or better
- RAM: 8 GB
- GPU: Dedicated graphics card with 2 GB VRAM
- Storage: 4 GB available space
- Display: 1920x1080 resolution

These specs will ensure smooth performance for a simple 2D isometric game created in Godot, allowing for better visual quality and faster load times.

## Required Features

- 2D Graphics Rendering: Capable of handling isometric 2D graphics
- Audio Support: Compatible with common audio formats (e.g., OGG, WAV)
- Input Handling: Support for keyboard and mouse inputs
- Save/Load Functionality: Ability to save and load game progress
- UI System: For in-game menus and HUD elements
- Physics Engine: Basic 2D physics for object interactions
- Particle System: For visual effects

These features are essential for running a single-player 2D isometric game without any networking requirements.
