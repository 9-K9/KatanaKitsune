DIALOGIC  2.0-Alpha-14 -> 2.0-Alpha-20
  - Alpha-14 targeted Godot 4.2 and did not compile on 4.7:
    node_name_label.gd declared _set() without returning on all paths, which

  - Alpha-20 targets 4.5+ and fixes it upstream.
  - Three local patches to the vendored addon were checked one by one against
    alpha-20 and all three were already fixed upstream, two with better
    implementations. Nothing was lost in the swap.

    errors. That is the global class cache populating. Restart the editor and
    it clears. Not a real failure.

ENEMY TAUNTS  (commit 7fe8078)
  - New `alert` state: stands guard, glances to random directions, locks on
    when the player is inside detection range.
  - New `taunt` state: rooted, facing the player, until the dialogue is
    dismissed, then straight into the hunt.
  - TauntComponent (scripts/components/TauntComponent.gd): standalone node
    holding the timeline path and the spoken/speaking latches. Talks only to
    Dialogic and its own exports, so it drops onto an NPC or boss unchanged.
    A static latch stops two monsters taunting over each other, since Dialogic
    has one global timeline.
  - Lines live in dialogue/enemies/.
  - Damage taken mid-taunt still lands but does not route to `hurt` — that
    would leave the timeline running with nothing waiting on it.
  - The requested 100px leash was NOT used: it sits below attack_range (110),
    so the monster would have disengaged from inside its own swing and never
    landed a hit. Used the existing lose_interest_range of 560 instead.

TARGETING REFACTOR  (commit 11fd472)
  - Targeting was answered two ways: playerAttack queried the live ActionArea
    overlap, while the provoke hook read a cached enemyBody kept in sync by
    Area2D signals. They could disagree, and the cache held only one body.
  - Both now go through the character: blade_targets() and current_target().
  - enemyBody, its two signal handlers and the scene's body_entered connection
    are gone.
  - Also: PlayerClass no longer re-walks the string path
    "CollisionChecker/RayCast2D/ActionArea" on every swing, and the provoke
    check now gates on input before running the overlap query rather than
    after.

TITLE SCREEN

TOOLING  (commits 67333af, 4f63da4)
  - tools/check_scene_connections.gd + tools/check-connections.sh
  - Catches signal connections that have gone stale. A .tscn wires signals by

  - Run it after ANY change to a scene's node tree:

        tools/check-connections.sh scenes/title_screen.tscn
  - Exits non-zero, so it works as a pre-commit gate.
  - The wrapper finds the engine itself ($GODOT, then PATH, then searches $HOME).
  - Validated by breaking things on purpose: a stale from= path is caught both

  - Its first draft had a false positive (flagged the cheats menu Immortality
    CheckButton, which reports through `toggled`, not `pressed`). Fixed to
    accept pressed/toggled/button_up/button_down.
